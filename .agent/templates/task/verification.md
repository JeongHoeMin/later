# Verification

## T-R1-1

- Requirement / AC: R1 / AC-R1-1
- Behavior: 입력·조건과 기대 결과.
- Verification Type: UNIT (또는 INTEGRATION / E2E / MANUAL / EVAL)
- Test: 실제 파일 경로와 테스트 이름. 구현 전에 설계하고 작성 후 연결한다.
- RED: NOT_STARTED
- GREEN: NOT_STARTED
- REFACTOR: NOT_STARTED
- Result: NOT_STARTED
- Evidence: 실행 명령과 기대 실패 이유 / 실제 결과 요약.

## Final Verification

관련 테스트, 변경 앱 전체 Suite, 타입·린트·빌드, 필요한 Eval과 회귀 결과를 적는다.
문서 전용 작업은 링크·YAML·템플릿·지침 일관성 검토를 기록한다.
N/A는 이유를 쓰고 실행 불가와 PASS를 구분한다.

## Service Policy Verification

[서비스 정책](../../../docs/service-policy.md)의 수치·조건·예외·미지원 범위를 구현과 대조한 결과와 갱신 항목을 적는다. 영향이 없으면 해당 없음과 이유를 기록한다. 정책 문서 검증 전 완료로 표시하지 않는다.
