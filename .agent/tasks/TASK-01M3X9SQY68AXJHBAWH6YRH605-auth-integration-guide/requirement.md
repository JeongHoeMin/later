# Requirement

Goal: Swagger 조회와 기존 서버 인증 계약에 맞춰 모바일 인증 연동 방법·현재 구현 경계를 설명하고 HTTP 클라이언트/세션 실제 연결을 검증한다.

R1 AC-R1-1: 네 제공자 로그인 입력과 Apple start, 저장 후 재시작 refresh/회전, logout을 실제 공통 코드로 연결해 검증한다(외부 HTTP/저장 경계만 대체).
R2 AC-R2-1: GET Swagger 주소, 환경 설정, 앱 범위 singleton 조립, 토큰/오류 처리 및 SDK/화면 미연결을 문서에서 정확히 구분한다. 문서 링크와 예제가 실제 코드 계약과 맞는다.

Out of scope: 제공자 SDK와 화면 연결은 요청 범위 확인 답변이 필요한 상태. App.tsx 임시 로그인은 아직 실제 인증이 아니다. main 추가병합/배포는 이 Task에 포함하지 않는다.

R3 AC-R3-1: 연동 리뷰에서 발견한 갱신 저장 중 access 만료 상황에서도 만료 토큰을 반환하지 않고 자동 재시도 없이 실패한다. 기존 세션 동작 결함의 보완이며 사용자 승인 인증 연동 범위.
