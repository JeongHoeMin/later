## 다음 작업: 승인 대기

구글 소셜 로그인과 서비스 토큰·세션 기능은 구현했다. 카카오·네이버 어댑터와 모바일에서 실제 제공자 로그인은 아직 구현·검증하지 않았다.
현재 활성 Product Task와 RED 상태 테스트는 없다. 기록 작업 후 카카오 인증 어댑터와 HTTP provider 확장을 사용자에게 제안하고 승인을 받는다.
승인되면 TASK-008을 템플릿으로 만들고 공식 카카오 문서에서 앱에 귀속된 credential 검증 방식을 확인한 뒤 R/AC/Test 설계를 작성한다.
그 다음 첫 미구현 Behavior 테스트를 작성하고 올바른 RED를 확인한다. credential 방식·환경 변수는 확인 전 확정하지 않는다.
feat/auth 작업은 아직 main에 병합하지 않았다. auth 브랜치를 push하거나 PR을 병합하는 것은 별도 승인 범위다.
