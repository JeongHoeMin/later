# Requirement

Goal: 공통 인증 HTTP 클라이언트에 모바일 세션 수명주기를 연결한다. 사용자 전체 순차 진행 승인 범위.

## R1 - 토큰과 복원
- AC-R1-1: access token은 메모리에만 유지하고 refresh token과 회원/제공자 표시 정보는 SecureStore에 저장한다. 저장 성공 후에만 로그인 상태를 게시한다.
- AC-R1-2: 재시작 시 서버 refresh 검증 후 복원하며 회전된 refresh token을 먼저 저장한다. 저장 정보만으로 로그인 처리하지 않는다.

## R2 - 갱신과 종료
- AC-R2-1: 유효 access token을 사용하고 만료 전에 갱신한다. 동시 갱신은 한 HTTP 요청을 공유하며 login/refresh/logout 상태 변경을 직렬화한다.
- AC-R2-2: refresh401은 로컬 삭제, 일시 네트워크 실패는 복원 자료 유지. logout은 메모리와 저장 데이터를 삭제하고 서버 세션 종료를 요청한다. 실패를 숨기거나 자동 재시도하지 않는다.
- AC-R2-3: 저장 실패 시 로그인/회전 응답을 성공으로 노출하지 않고 서버 세션 폐기를 시도한다. native 오류 내용을 로그/사용자 오류에 노출하지 않는다.

Out of scope: 소셜 SDK/UI 및 실제 제공자 계정/기기 로그인은 다음 Task. 회원 id 캐시는 표시 정보로만 사용한다.
