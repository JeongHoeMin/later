# Requirement

## R1

- AC-R1-1: 기획과 후속 auth 요구를 서버 코드·HTTP 계약·자동 테스트와 대조한다. auth 범위와 저장/결제 후속 도메인을 구분한다.
- AC-R1-2: 실제 제공자 계정 검증 가능 여부를 로컬 환경 설정 유무·앱 진입 코드로 확인하며 비밀값은 출력하지 않는다. 불가능하면 실제 검증 완료로 표시하지 않고 준비 항목을 기록한다.
- AC-R1-3: 낡은 기획 API 경로와 연동 안내의 정리 주기를 수정하고 점검 보고를 docs에 기록한다.

## Service Policy Impact

사용자 정책 변경 없음. 현재 정책을 판단 기준으로 대조한다.

## Service Architecture Impact

구성 변경 없음. 저장소 구현과 실제 기기/서버 실행 검증을 구분한다.

## Out of Scope

새 기능·모바일 수정·실계정 가입/외부 콘솔 변경·운영로그 수집/경보·배포·운영 DB 접속.
