# Requirement

## R1 · 만료 인증 데이터 배치 정리
- AC-R1-1: expiresAt <= 실행 기준 시각인 Apple/Naver 로그인·연동 시도와 AuthSession을 삭제한다. 세션의 RefreshToken은 FK cascade로 삭제한다.
- AC-R1-2: 만료 전 시도·세션·사용 완료 또는 폐기된 세션의 토큰과 회원·소셜 계정은 보존한다. 토큰 단독 삭제는 하지 않는다.
- AC-R1-3: 한 실행에서 테이블별 최대 500개만 정리한다. 만료 시각/ID 순서로 처리하고 반복 실행은 안전하다. DB 잠금과 트랜잭션으로 여러 서버의 동시 실행을 보호한다.

## R2 · 주기 실행과 장애 처리
- AC-R2-1: API 시작 후 1시간마다 실행하며 첫 실행도 1시간 후다. 프로세스 내 중복 실행을 건너뛰고 종료 시 timer를 제거한다.
- AC-R2-2: DB 장애는 원문·토큰 없이 기록하고 다음 주기에 재시도한다. 정리 오류로 HTTP 서버를 종료하지 않는다. 로그에는 집계 건수만 포함한다.

## Out of Scope
사용자·소셜 연결·콘텐츠 삭제, 인증 API 요청 제한, 운영 DB 적용, 모바일. 만료되지 않은 폐기 세션의 조기 삭제 없음.
