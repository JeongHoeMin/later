# Requirement

이 문서는 카카오·네이버 추가 전 사후 기록 baseline이다. 아래의 현재 상태·검증 수치·미구현 설명은 당시 기록 기준이며 이번 문서 이관의 실행 결과와 구분한다. 최신 제공자 상태는 [네이버 Task](../TASK-01M3X3N5YE122YB2CP9Z2642J7-naver-social-auth/task.yaml)를 참고한다.

## Background / Goal

소셜 계정 회원 연결과 Prisma 저장의 기존 구현을 새 Agent가 이어받을 수 있도록 2026-10-02 사후 기록한다.
이 문서는 과거 구현의 기대 Behavior를 현재 코드와 대조해 정리한 baseline이며 새로운 기능 구현 승인이 아니다.
근거 커밋: ef3af2b, 0fce1b5, c512583, 554b5a4, 0a2a61e, 98e855e, c5336ad.

## R1 - 기존 회원 조회·신규 회원 연결

- AC-R1-1: 미등록 계정은 null, 등록 계정은 연결된 회원을 반환하고 신규 생성 시 두 레코드를 함께 저장한다.

## R2 - 중복 가입의 롤백·재조회

- AC-R2-1: 중복 생성은 새 회원을 남기지 않으며 동시 요청은 같은 회원을 반환한다.

## R3 - 제공자별 계정 분리

- AC-R3-1: subject가 같아도 provider가 다르면 별도 회원으로 저장한다.

## R4 - 오류 전달

- AC-R4-1: 중복 후 재조회가 실패하거나 일반 오류가 발생하면 원래 오류를 전달한다.

## Out of Scope / Limits

자체 비밀번호 회원가입과 이메일 기반 자동 계정 통합은 범위 밖이다.
