# Requirement

## R1 · 구현된 서비스 정책
- AC-R1-1: docs/service-policy.md에 현재 코드로 구현한 회원 식별/로그인/토큰/로그아웃/탈퇴/연결 조회·추가/일회용 시도/만료 정리/요청 제한을 정리한다. 미구현과 운영 적용 상태를 구분하고 근거 파일 링크를 제공한다.
- AC-R1-2: 기존 docs/social-login-process.md의 오래된 회원 존재 확인 및 정리 문구를 수정하고 정책 문서로 연결한다.
## R2 · 향후 갱신 규칙
- AC-R2-1: .agent/AGENTS.md 및 project.md에 서비스 정책 변경 시 동일 Markdown 문서를 구현·검증·Task 완료 전에 갱신하는 규칙과 링크를 추가한다. Task 템플릿에도 정책 영향·갱신/해당 없음 확인을 남긴다.
## Out of Scope
미구현 기획의 정책 확정, 법적 약관 작성, 모바일 코드 변경.

## Service Policy Impact

[서비스 정책](../../../docs/service-policy.md)을 현재 구현 정책 기준 문서로 만든다. 기존 구현을 정리하고 요청 제한 Task의 새 정책을 포함한다. 문서화가 새 미구현 서비스 규칙의 승인을 뜻하지 않는다.
