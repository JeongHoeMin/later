# 요구사항

R1: docs 개발·기획과 현재 코드/Task를 대조해 첫 MVP를 정리한다.
- AC-R1-1: 서버와 모바일 기능·상태·근거를 독립 기록한다.
- AC-R1-2: 완료·부분 구현·미구현·외부 검증 미확인을 구분하고 취소 Task를 완료로 집계하지 않는다.

R2: 사용자 결정으로 장소 액션과 구독을 첫 MVP에 포함하고 모호한 사항을 대화로 확정한다.
- AC-R2-1: 장소·구독·보관 기능을 첫 출시 완료 기준에 포함한다.
- AC-R2-2: 미확정 수치를 예시와 구분하고 결정 ID를 기록한다.

R3: Free는 초기 100개·30일 모두 적용하며 변경 가능한 정책을 저장 시점별로 보존한다.
- AC-R3-1: 기존 저장물은 이전 정책을 유지하고 이후 저장부터 신규 정책을 적용한다고 기록한다.
- AC-R3-2: 서버 정책 버전/항목별 조건 제공과 모바일의 현재/기존 정책·만료일 구분 표시를 기록한다.
- AC-R3-3: 혼합 정책의 개수 집계·한도 도달 처리·Plus 전환 등 미확정 규칙을 확정 사실과 구분한다.
- AC-R3-4: 전체 보관량이 현재 한도 이상이면 신규 저장을 거부하고 기존 항목을 유지한다. 한도와 같은 경우도 거부한다고 기록한다.

R4: 만료·삭제를 자동 진행하고 구독 복구와 공통 콘텐츠 수명을 분리한다.
- AC-R4-1: 만료 항목은 화면에서 숨기고 개수 집계에서 제외한다.
- AC-R4-2: 만료 후90일 동안 연결을 보존하고 제한 해제 구독 시 복구한다. 유예 종료 후 자동 연결 삭제.
- AC-R4-3: 연결 삭제와 Content/AI 분석 삭제를 구분한다. 마지막 연결 삭제 이후 연속180일 무연결이면 영구 삭제한다. 새 연결 시 기간 초기화.
- AC-R4-4: 개월 대신24시간 기준 일수로 계산한다. 구독 종료 미확정 부분은 구분한다.
- AC-R4-5: 자동 연결 삭제는 현재 만료 시각+90일이다. 권한 종료로 만료되면 저장일로 소급하지 않고 종료 시각부터 계산한다. 재구독으로 복구 후 다시 만료되면 새로운 만료 시각+90일이다. 직접 삭제는 즉시 삭제 예외다.
- AC-R4-6: 이미 만료 상태인 항목의 재조회/중복 이벤트만으로 기한을 연장하지 않는다. 실제 복구 후 재만료 전이를 구분한다.

R6: 먼 만료는 날짜, 가까운 만료는 남은 일수·시간·분으로 표시한다.
- AC-R6-1: 24시간 미만은 N시간 후 만료, 1시간 미만은 N분 후 만료. 실제 만료 시점에 숨긴다.
- AC-R6-2: 30일 초과는 날짜, 24시간 이상~30일 이하는 일수, 1시간 이상~24시간 미만은 시간, 1시간 미만은 분으로 표시한다. 실제 남은 시간으로 단위를 선택하고 해당 단위로 올림한다. 1분 미만은1분 후 만료.

R7: 개수/기간 구독, 할인 묶음, 영구보관/개수 무제한 상품 방향과 상태별 정책을 표로 정리한다.
- AC-R7-1: 구독 전/중/재구독/갱신 취소/실제 종료/환불을 구분하고 두 권한 축과 서버·화면 책임을 기록한다.
- AC-R7-2: 확정 규칙·제안·기존 승인과의 충돌·영구보관 의미 등 미확정을 구분한다.
- AC-R7-3: 기간 종료형 갱신 취소와 즉시 취소/일부 환불을 구분한다. 최신 N개 유지와 상황별 만료/연결 삭제/복구 표를 기록하고 미확정 기산 조건을 구분한다.

R8: 사용자 상품안의 월 구독 가격을 서버 운영·AI·무료 사용자 비용으로 재추천한다.
- AC-R8-1: 90/180일·300/500개·묶음 상품과 가격 제안을 기록한다. 실제 운영비/사용량 미정과 가정·출처·추천의 한계를 구분한다.
- AC-R8-2: 구독 중만 기간 무제한·종료 시 원래 저장일부터30일 적용·신규 저장 한도 차단/알림을 확정 조건으로 기록한다.

R9: 실패 구간별 안내·재시도 요구를 구분한다.
- AC-R9-1: 로그아웃 시 로그인 안내, 분석 실패 알림, 실패 항목 유지/폐기 보류를 기록한다.
- AC-R9-2: 모바일3번/2초 간격·작업 등록5번·작업 실행3번을 기록하고 최초 포함/추가 횟수 및 고정/지수 간격 미확정을 구분한다. 오프라인 의미와 결정 필요 사항을 설명한다.

R5: 사용자 직접 삭제와 모바일 주의 팝업을 포함한다.
- AC-R5-1: 직접 삭제는 사용자 연결만 즉시 삭제하고 공통 Content/AI 분석과 다른 사용자 연결을 보존한다.
- AC-R5-2: 삭제 전 확인/취소 팝업, 연결 삭제 후 구독 복구 불가 안내, 서버 성공 이후 화면 갱신을 기록한다.

범위: 문서 정리만 수행한다. 제품 구현·외부 결제/배포 작업은 제외한다. 현재 구현 정책/구성은 바뀌지 않아 기준 문서 변경은 해당 없음.

## R10: 전체 비용과 손익 기반 상품 권고
사용자 요청: 발생 가능한 비용을 산정하고 손익을 계산해 가격·보관·분석 제공량을 정한다. 공식 단가/추정 구분, 고정/변동/인건비/초기 투자/결제/마케팅 포함, 전량 사용·전환율 저하·원가 상승 비교, 수정 가능한 계산 파일과 문서 일치가 완료 기준이다. 상품 구현은 범위 밖이다.

R10 후속 승인: 사용자 첨부 표의 모든 상품 가격/보관/분석량과 첫 가입20건·추가50건2900원을 확정한다. 지급일·이월·추가권 유효기간·동시 구독 분석 지급량은 별도 결정 대상이다.

사용자 우선순위 변경: 구독 상세 설계는 개발 시점까지 보류한다. 승인된 상품/보관 생명주기 기록은 유지하고 콘텐츠 분류 기준을 먼저 논의한다. 구독 MVP 범위 제외 요청은 아니다. DISC-015 콘텐츠 분류는 미확정이며 구현은 진행하지 않는다.

R11: AI 필요 여부 우선 판정. 구조화 정보가 충분한 지도 장소 링크 등은 AI 없이 저장/검색하고 신규 AI 분석량을 차감하지 않는다. 분석 잔량 소진은 이 경로를 차단하지 않으며 보관 제한은 적용한다. AC-R11-1: 직접 추출/AI/분석 불가를 구분해 문서 기록. AC-R11-2: 지원 출처·필수 필드 등 미확정 범위와 기존 보류 사항 구분. 구현 범위 밖.

R11 후속: 사용자 직접 태그 입력은 MVP 제외. 장소 검색 목표는 지역+업종. URL 식별·API/구조화 정보·메타데이터·본문 수집·AI 의미 해석·접근 불가의 경우를 구분해 비교한다. 지원 사이트는 미확정.

R11 후속 승인: 현재 콘텐츠 경로 비교 수준을 기획 기준으로 기록한다. 지원 출처/실패 데이터 처리/중복 저장/검색 품질/공유 예외/출시 기준은 후속 결정이며 구독 상세 설계 보류는 유지한다.

R12: 지도/SNS/영상/상품/블로그/일반웹/뉴스/PDF/이미지/GitHub 지원 대상과 URL 우선 판별, multilingual-e5-small+pgvector 자연어 검색 확정. 분석 실패/출시 기준 보류, 공유 예외 순차 질문. URL 단서와 실제 콘텐츠 확인을 구분한다.

R13: 오프라인 공유는 즉시 실패 안내·저장 없음으로 확정. 기기 임시 저장/자동 재전송 제외. AC-R13-1: 오프라인과 전송 도중 실패의 수신 불확실성을 문서에서 구분한다.

R14: 로그아웃 상태 공유는 로그인 안내 후 로그인 완료 시 원래 공유한 콘텐츠 저장 자동 재개. AC-R14-1: 인증 전 저장 미확정, 다시 공유 불필요, 오프라인 실패 정책과의 관계 기록. 취소/실패/화면 종료의 대기 데이터 처리는 미확정.

R15: 모바일 업로드/서버 작업 등록/작업 실행은 최초 포함 총3/5/3회로 확정. 추가 재시도 최대2/4/2회. AC-R15-1: 총 횟수와 추가 횟수의 대응을 문서에 명시하고 간격 미확정과 구분한다.

R16: 모바일 업로드 총3회, 실패 후 대기2초/4초 지수 backoff 확정. AC-R16-1: 시도 순서와 마지막 실패 안내, 서버 간격 미확정 구분 기록.

R17: 서버 작업 등록 총5회 대기2/4/8/16초, 작업 실행 총3회 대기2/4초 지수 backoff 승인. AC-R17-1: 모바일 포함 구간별 최종 표와 과거 미확정 대체 관계 기록. 구현/timeout/재시도 대상 오류 설계는 범위 밖.

R18: 사용자 본인이 보관 중인 동일 콘텐츠를 다시 저장하면 중복 항목 없이 기존 연결의 저장일/만료일 갱신. AC-R18-1: 전체 공통 콘텐츠 중복과 사용자 보관 중복 구분, 이전 날짜 유지 제안 대체 기록. 정책 버전/만료 유예 항목/한도 도달 처리는 후속 결정.

R19: 동일 사용자 콘텐츠 재저장은 재저장 시점 현행 정책 적용, 저장일/만료일/정책 스냅샷 갱신. AC-R19-1: 다시 저장하지 않은 항목의 이전 정책 유지 및 정책 버전 불변과 구분해 기록한다.

R20: 만료 숨김/90일 삭제 유예 연결 재저장은 한도 미만에서 기존 연결 복구·현행 정책·저장일/만료일 갱신·이전 삭제 예약 취소. 한도 도달 차단. AC-R20-1: 복구 성공/차단 상태와 재만료 새90일 기산 구분 기록.

R21: 보관량(C)/보관기간(T)/AI 분석 사용(A)을 독립 규칙으로 문서 구성하고 상황별로 조합한다. AC-R21-1: 사용자별 활성 개수·날짜/생명주기·AI 필요 여부/잔량 분리. AC-R21-2: 신규/재저장/만료 유예 복구/기존 검색의 조합 표와 미확정·보류 구분. 제품 구현 범위 밖.
